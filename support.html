Macro Usage Exporter support

For help, bug reports, privacy questions, or security concerns, email utilitystacklabs@gmail.com.

Include the exact macro key, whether you selected space keys, the displayed error, and the approximate number of pages reached. Do not email page bodies, exported CSV files, credentials, or other sensitive content unless we arrange a secure channel.

Use the app

  1. Open Apps → Macro Usage Exporter in Confluence.
  2. Enter the exact macro key. Optionally enter up to 20 comma-separated space keys.
  3. Select Find pages. Download the CSV only when the scan says it is complete.

The report has one row per matching page, not per macro instance. It includes only pages the signed-in user can view and Confluence search has indexed. It searches pages, not blog posts. A zero-result report cannot rule out restricted or unindexed content.

If a scan fails

Cancelled, failed, and oversized scans do not offer a complete CSV. If Confluence is limiting searches, wait and retry. If a report exceeds 10,000 unique pages, narrow the space selection.
