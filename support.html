Macro Usage Exporter support

For help, bug reports, privacy questions, or security concerns, email utilitystacklabs@gmail.com.

Include the exact macro key, whether you selected space keys, the displayed error, and the approximate number of pages reached. Do not email page bodies, exported CSV files, credentials, or other sensitive content unless we arrange a secure channel.

Use the app

  1. Open Apps → Macro Usage Exporter in Confluence.
  2. Enter one exact macro key. Optionally enter up to 20 comma-separated space keys, not space names.
  3. Select Find pages. Download the CSV only when the scan says it is complete.

A site administrator installs the app. Licensed Confluence users run reports within their own page permissions. A Confluence app administrator can check Confluence administration → Macro Usage for the indexed macro key; the macro vendor's documentation may also identify it. The editor's display name can differ from that key. For example, an Info panel may be indexed as panel; this is not a default or a promise of results on every site.

The report has one row per matching page, not per macro instance. It includes only pages the signed-in user can view and Confluence search has indexed. It searches pages, not blog posts. A zero-result report cannot rule out restricted or unindexed content. The on-screen table previews up to 200 pages; the completed CSV includes every returned page up to the report limit. Open the downloaded CSV using your spreadsheet's CSV import/open workflow and handle page titles and links according to your organization's policy.

If a scan fails

Cancelled, failed, and oversized scans do not offer a complete CSV. If Confluence is limiting searches, follow the retry timing shown. If a report exceeds 10,000 unique pages or too many search pages, narrow the space selection.
