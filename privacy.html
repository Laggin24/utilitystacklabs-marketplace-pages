UtilityStack Labs / Privacy

Privacy policy for Macro Usage Exporter

Effective September 29, 2026. UtilityStack Labs publishes Macro Usage Exporter for Confluence. For privacy questions, contact utilitystacklabs@gmail.com.

Information the app uses

When a signed-in user runs a report, the app uses their macro key and optional space keys to search Confluence as that user. Confluence returns matching page IDs, titles, space keys, and update dates. The app uses those fields to show a page-level report and create a CSV with links to the pages. It does not request page bodies.

Where information goes

Search requests and result metadata pass through Atlassian Forge and Confluence to the user's browser. The app declares no external data egress or remote service. It does not send report contents to UtilityStack Labs infrastructure or use an app database or Forge storage to retain reports. Its own code does not log report rows, query values, or credentials. Atlassian may process platform logs under its own policies.

Retention and user choices

Report rows remain in the active browser page until it is closed or a new scan clears them. A CSV is created in the browser only after a complete scan; a copy downloaded by the user is stored on their device under their organization's controls. Users can avoid creating a report by not running a scan and can delete downloaded copies themselves. UtilityStack Labs has no retained report database to search, export, or erase.

Permissions

The app requests only search:confluence. Confluence permissions determine which pages the signed-in user can find. A zero-result report does not prove that restricted or unindexed pages do not exist.

Contact and updates

Send privacy or security questions to utilitystacklabs@gmail.com. We may update this policy if the app's data practices change; the effective date above will then be revised. This support site is hosted on GitHub Pages, whose own practices apply when visiting these pages.
